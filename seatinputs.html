Seat inputs

Seat inputs are a type of security lock on sanddollar that require an external source to be solved. For example: We had used the env_feed website to get past the first SEAT INPUT message on sanddollar. They are typically found within 1-4 months and possibly a few days if we're lucky.


Another example of seat inputs is the medusa recovery mode. in the center of the screen there is a warning indicating that a seat input request is essential
